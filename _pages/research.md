We develop methods and tools to make complex software systems easier to design, analyse, and test. Our work connects <strong>formal methods</strong> with <strong>software engineering</strong>: we use precise models to describe how a system should behave, then check those models and the software built from them against its requirements.

<div class="research-areas">
  <section class="research-area"><span class="section-number" aria-hidden="true">01</span><div><h2>Modelling and software architecture</h2><p>We use <strong>model-driven engineering</strong>, UML-based languages, software architecture descriptions, and <strong>Abstract State Machines</strong> to represent the behaviour and structure of a system before implementation. These models help us make requirements precise, explore design choices, and connect specifications to executable software. ASMETA brings together tools for working with Abstract State Machine models throughout this process.</p></div></section>
  <section class="research-area"><span class="section-number" aria-hidden="true">02</span><div><h2>Validation and verification</h2><p>We examine whether models and implementations behave as intended through <strong>simulation</strong>, scenario-based validation, and <strong>model checking</strong>. We also study how to analyse systems built from interacting components and how to monitor important properties while a system is running. This work helps identify design errors and assess the effect of changes before they reach deployed software.</p></div></section>
  <section class="research-area"><span class="section-number" aria-hidden="true">03</span><div><h2>Software testing</h2><p>We develop <strong>model-based</strong>, <strong>combinatorial</strong>, and <strong>search-based testing</strong> techniques to generate useful test cases and reveal failures. Our work covers state-based systems, software product lines whose features evolve, and controllers described in simulation environments. We also evaluate test effectiveness and look for ways to keep tests reliable as models and requirements change.</p></div></section>
  <section class="research-area"><span class="section-number" aria-hidden="true">04</span><div><h2>Dependable and data-driven systems</h2><p>We apply these methods to <strong>cyber-physical systems</strong>, autonomous behaviour, and medical software, where faults can affect safety. We analyse failures, check whether software updates preserve required behaviour, and use models to enforce safety constraints at runtime. We also investigate how language models can assist formal specification and how to validate data used by software when real-world datasets are limited.</p></div></section>
</div>

## Application domains

Our case studies include autonomous vehicles, drones, e-bikes, medical devices, and self-adaptive systems.
